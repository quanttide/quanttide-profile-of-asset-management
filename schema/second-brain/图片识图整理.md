## 图片一：第二大脑九宫格

### 原始 OCR

```
第二大脑       
                         规则        模型        程序
               竞法  bylaw    specification    toolkit
程序型   一般法  handbook    gallery        platform
               法理  tutorial    essay          laboratory

                          intention   insight    roadmap    未来
陈述型               brochure   profile    journal    现在
（context）       history      library     report     过去
                  
                           自我记忆       语义记忆      事件记忆
```

### 修正后（对照章程）

OCR 的核心识别正确，细节修正如下：

- "竞法" → **宪法**（最高约束力）
- "一般法" → **法律**（中等约束力）
- 列标题"规则/模型/程序" → 章程用词为 **人类友好/AI友好/规则引擎友好**
- 底部标签"自我记忆/语义记忆/事件记忆" → 对应陈述型九宫格的 **自我类/语义类/事件类**
- "laboratory" 与 "Example" → 章程中为 **Example（示例程序）**，仓库命名为 `laboratory`

**结论**：图片与章程完全一致，OCR 的少量用词差异不影响理解。


### 修正后

| 原始 OCR | 修正 | 原因 |
|----------|------|------|
| `gtdata` | `qtdata` | 量潮产品命名：qt = QuantTide |
| `gtclass` | `qtclass` | 同上 |
| `gtrecruit` | 忽略 | OCR 误识别杂讯，无此仓库 |
| `quanttide-techprivate` | `quanttide-tech-private` | 漏了连字符 |
| 重复行 | 合并 | OCR 重复识别了部分内容 |

### 结构化整理

```
公开层 (quanttide-tech)
├── 按资产类型划分，下层按业务线展开
├── 与自媒体账号对齐，不刻意区分归属
└── qtdata, qtclass 等产品仓库

领域层 (quanttide)
├── 按业务领域划分，完整列表见 第二大脑三层架构.md
└── 可按"人/财/事"三大类归类（见下方确认结果）

私有层 (quanttide-tech-private)
├── 按业务域划分，内部活动有明确边界
├── qtclass-private  — 课堂业务域
└── qtdata-private   — 数据业务域
```

## 果总确认结果（2026-07-20）

1. **公开层组织原则**：按资产类型划分，下层按业务线展开。与自媒体账号对齐，不刻意区分"谁属于谁"，让客户看到"我们能干什么"即可。`qtrecruit` 为 OCR 杂讯，无此仓库。

2. **私有层组织原则**：按业务域划分，内部活动有明确边界。`qtrecruit-private` 为 OCR 杂讯。

3. **领域层完整列表**：OCR 列出的 6 个领域不全，已补充为 19 个领域（见 第二大脑三层架构.md），按"人/财/事"三大类归类。

4. **"人/财/事"划分**：确认为领域第二大脑的顶层分类：
   - **人**：人事、组织、创始人
   - **财**：商务、财务、经济
   - **事**：数据、课程、产品、资产、新媒体、战略、智能体、知识、软件、身份认证、支付、执行、DevOps
