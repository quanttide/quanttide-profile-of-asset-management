# 第二大脑三层架构

> 量潮第二大脑按可见性分为三层：公开、领域、私有。
> 分别对应三个 GitHub 组织账号。

## 三层定义

| 层级 | GitHub 组织 | 组织原则 | 可见性 |
|------|-----------|----------|--------|
| 公开层 | `quanttide-tech` | 按**资产类型**划分，下层按业务线展开；与自媒体账号对齐 | 全网可见 |
| 领域层 | `quanttide` | 按**业务领域**划分，每领域是独立知识体系 | 组织内部 |
| 私有层 | `quanttide-tech-private` | 按**业务域**划分，内部活动有明确边界 | 授权访问 |
