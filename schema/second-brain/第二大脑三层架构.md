## 三层定义

| 层级 | GitHub 组织 | 可见性 | 内容 |
|------|-----------|--------|------|
| 公开层 | `quanttide-tech` | 全网可见 | 开源项目、对外产品、教学资源、社区互动 |
| 领域层 | `quanttide` | 组织内部 | 按领域划分的第二大脑（人事/组织/商务/财务/数据/课程等） |
| 私有层 | `quanttide-tech-private` | 授权访问 | 个人工作空间、敏感数据、私有档案 |

## 领域第二大脑细分

| 领域 | 说明 |
|------|------|
| quanttide-human | 人事管理 |

| quanttide-business | 商务管理 |
| quanttide-finance | 财务管理 |
