# 第二大脑九宫格资产图式

> 依据：量潮第二大脑资产图式章程（2026年6月版）
> 18 种标准资产 + Context（入口）+ Archive（出口）

## 程序型记忆（怎么做事）

约束力维度：宪法 > 法律 > 法理
消费对象维度：规则引擎友好 > AI友好 > 人类友好

```
                    人类友好           AI友好            规则引擎友好
                  (可读性/启发性)    (结构化/可解析)     (可执行性)
        ┌─────────┬─────────────────┬─────────────────┬─────────────────┐
宪法    │         │     Bylaw       │  Specification  │    Toolkit      │
(最高)  │         │     工作章程     │    工程标准      │    工具箱       │
        ├─────────┼─────────────────┼─────────────────┼─────────────────┤
法律    │         │    Handbook     │    Gallery      │   Platform      │
(中等)  │         │    工作手册     │    工作案例      │    平台         │
        ├─────────┼─────────────────┼─────────────────┼─────────────────┤
法理    │         │    Tutorial     │     Essay       │  Example        │
(基础)  │         │    工作教程     │    论文      │   (Laboratory)  │
        └─────────┴─────────────────┴─────────────────┴─────────────────┘
```

## 陈述型记忆（知道什么）

时间维度：过去（已履行）→ 现在（履行中）→ 未来（将履行）
类型维度：事件类（做什么）→ 语义类（信什么）→ 自我类（我是谁）

```
                    事件类              语义类              自我类
                  (行动计划)          (认知参考)          (身份叙事)
        ┌─────────┬─────────────────┬─────────────────┬─────────────────┐
未来    │         │    Roadmap      │    Insight      │   Intention     │
(将履行)│         │    工作蓝图     │    工作洞察      │   愿景      │
        ├─────────┼─────────────────┼─────────────────┼─────────────────┤
现在    │         │    Journal      │    Profile      │   Brochure      │
(履行中)│         │    工作日志     │    工作档案      │   宣传册        │
        ├─────────┼─────────────────┼─────────────────┼─────────────────┤
过去    │         │    Report       │    Library      │   History       │
(已履行)│         │    工作报告     │    工作参考      │   工作历史      │
        └─────────┴─────────────────┴─────────────────┴─────────────────┘
```

## 两个不占格资产

| 资产 | 角色 | 说明 |
|------|------|------|
| **Context**（上下文） | 入口 | 所有九宫格资产的默认入口，用户从日常工作中感知到模式或疑问后自然进入 |
| **Archive**（工作归档） | 出口 | 备份陈述型和程序型两类九宫格中所有格子的过时文件，确保持久化与可追溯 |
